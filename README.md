# ⛪ ADP Peniel - Web App Oficial

Aplicação Web oficial e responsiva da **Assembleia de Deus Peniel**, localizada em **Gurupi / Tocantins** (Av. Rio Grande do Norte, entre 17 e 18 - Setor Leste).

O projeto foi desenvolvido como um Web App moderno estilo *Progressive Web App (PWA)*, permitindo uma navegação fluida em dispositivos móveis (smartphones e tablets) e computadores.

---

### 🚀 Funcionalidades Principais

#### 🌐 **Área Pública**
- **Acesso Rápido:** Modais e atalhos interativos para **Culto ao Vivo**, **Contribuição via PIX (CPF)**, **Horários dos Cultos** e **Caixa de Pedido de Oração**.
- **Mural de Avisos:** Espaço dinâmico para notícias e recados importantes da igreja.
- **Design Totalmente Responsivo:** Layout fluido com menu inferior (*bottom bar*) para fácil navegação em smartphones.

#### 🔒 **Área do Membro (Painel Exclusivo)**
- **Autenticação:** Sistema de login e cadastro interativo para membros.
- **Plano de Leitura Bíblica:** Checklist de leitura com salvamento de progresso no navegador (`localStorage`).
- **Devocional Diário:** Mensagens e versículos bíblicos atualizados automaticamente.
- **Rádio Web & Louvores:** Player de áudio integrado para transmissão de louvores.
- **Dízimos & Ofertas:** Chave PIX e QR Code para facilidade de contribuição.
- **Pedidos de Oração:** Formulário direto integrado ao WhatsApp da intercessão.

---

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização moderna com Flexbox, CSS Grid, variáveis e media queries responsivas.
- **JavaScript (ES6+):** Lógica dinâmica, manipulação do DOM e persistência local via `localStorage`.
- **Font Awesome & Google Fonts:** Ícones e tipografia (*Plus Jakarta Sans*).
